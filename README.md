# BREAKGAME — Neon Brick Breaker

A responsive browser-based brick-breaker arcade game built with vanilla HTML, CSS, and JavaScript. No build tools or dependencies are required.

## Play
After enabling GitHub Pages, play at:
**https://jcllstudio.github.io/BreakGame/**

## Controls
- **Desktop:** Left/Right arrow keys or A/D to move the paddle.
- **Launch:** Spacebar or click/tap the play field.
- **Pause:** Spacebar while the ball is moving.
- **Touchscreen:** Drag across the play field to move; tap to launch.
- **Sound:** Toggle sound with the button below the game.

## Features
- Neon arcade visuals and classic brick-breaker gameplay.
- Responsive desktop, tablet, and mobile layout.
- Keyboard, mouse, and touch controls.
- Score, lives, levels, and locally saved best score.
- Increasing difficulty and multi-hit bricks on later levels.
- Lightweight vanilla HTML, CSS, Canvas, and JavaScript.

## Run locally
No installation is necessary. Clone this repository and open `index.html` in a modern browser.

```bash
git clone https://github.com/JCLLStudio/BreakGame.git
cd BreakGame
```

## Enable GitHub Pages
1. Open repository **Settings**.
2. Select **Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**.
5. Save. GitHub will publish the site at the Play URL above.

## Project files
- `index.html` — game page and interface.
- `style.css` — responsive arcade styling.
- `game.js` — game loop, collisions, scoring, sound, and controls.
